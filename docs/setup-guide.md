# Setup Guide

## 1. Project Requirements

To run SmartSupply AI, you need:

- A computer running Windows, Linux, or macOS
- A C++ compiler
- Git
- Internet connection for downloading the repository

## 2. C++ Compiler

### Windows

You can use MinGW/G++ or another C++ compiler that supports standard C++.

Check whether G++ is installed:

```bash
g++ --version
